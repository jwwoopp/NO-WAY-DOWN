# Audio assets

- All WAV files in this directory were created with [AMIX's 8-bit sound tools](https://amix-design.com/tl/tool-s-8bit-env/) and exported for use in this game.
- `MainGame_BGM.wav`: main gameplay background music
- Format: mono, 44.1 kHz, 16-bit PCM, approximately 60 seconds
- Playback: loops asynchronously from the game start until the process exits
