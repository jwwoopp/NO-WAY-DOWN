# NO WAY DOWN

> A vertical zombie survival roguelite.

좀비에게서 벗어나기 위해 새로운 층을 끊임없이 올라가는 수직 생존 로그라이트입니다.

## 핵심 플레이

1. 현재 층의 위험과 자원을 관찰합니다.
2. 좀비와 전투하거나, 피하거나, 소리로 유인합니다.
3. 문과 컨테이너를 조작하며 소음과 시간 비용을 지불합니다.
4. 위쪽 출구에 도달하면 현재 상태를 유지한 채 새로운 층으로 올라갑니다.
5. 아래층의 소음과 체류 시간이 다음 층의 좀비 배치와 추격 위험을 바꿉니다.
6. 사망하거나 옥상으로 탈출할 때까지 반복합니다.

## 첫 완성 목표

`4개 층 + 옥상`으로 구성된 5~10분 데모를 만듭니다. 데모는 옥상 탈출로 끝나지만, 새로운 층을 반복 생성하는 무한 상승 모드로 확장할 수 있게 설계합니다.

## 핵심 시스템

- 층별 독립 2D 논리 그리드
- 방·복도 템플릿을 조합한 층 맵
- 현재 층의 2D A* 경로 탐색
- 시야와 마지막 목격 위치
- 행동별 소음과 좀비 반응
- 문·계단·장애물을 이용한 경로 변화
- 체력·무기·아이템·경험치를 유지하는 `RunState`
- 피격 플래시·히트스톱·넥백을 활용한 전투 연출

## 기술 방향

- 언어: C++20
- 플랫폼: Windows
- 엔진: 학습용 `CraftEngine`
- 구조: `Engine → Level → Actor`
- 시뮬레이션: 렌더링과 분리된 고정 틱
- 후속 목표: Unity에서 동일한 규칙을 애니메이션·VFX·사운드로 확장

## 개발 단계

| 단계 | 내용 |
| --- | --- |
| 01.Engine | 엔진 루프, Level·Actor, Input, Renderer, 더블 버퍼링 |
| 02.Floor | 타일 맵, 플레이어 이동, 벽·문, 층 전환 |
| 03.Zombie | A*, 시야, 소음, 좀비 상태 머신 |
| 04.Combat | 전투, 아이템, 행동 기반 난이도, 사망·탈출 |

## 제외 범위

- 오픈월드와 온라인 멀티플레이
- 완전한 3D 건물 시뮬레이션
- 대규모 제작·인벤토리 시스템
- AI 생성 이미지를 최종 그래픽 정체성으로 사용하는 것
- 이해하거나 검증하지 못한 AI 생성 코드를 그대로 채택하는 것
