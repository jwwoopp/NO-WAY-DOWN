# NO WAY DOWN

> A vertical zombie survival roguelite.

좀비를 피해 12개 층을 올라가는 Windows 콘솔 생존 게임입니다.

## 현재 구현

- 텍스트 파일로 만든 12개 층의 맵, 문과 출구, 층 전환을 구현했습니다. 12층 출구에 도달하면 클리어합니다.
- 키보드와 마우스로 이동하고, 근접 공격과 총으로 좀비와 싸우거나 회복약을 사용할 수 있습니다.
- 좀비는 시야와 마지막 목격 위치를 바탕으로 추격·수색하며, 4방향 A*로 길을 찾습니다. 문을 열거나 총을 쏘면 주변 좀비가 소리 난 위치를 수색합니다.
- 닫힌 문은 이동과 시야를 막습니다. 좀비는 문을 부수거나 다른 경로를 찾을 수 있습니다.
- 체력·회복약·탄약은 `RunState`에 보관해 층을 넘어도 유지합니다. 추격 중인 좀비 일부도 다음 층으로 따라옵니다.
- 아이소메트릭 화면, 4방향 × 3프레임 캐릭터 스프라이트, 시야와 지도, HUD, 효과음·BGM, 타이틀·결과 화면을 적용했습니다.
- C++20과 Windows API로 만든 학습용 `CraftEngine`을 사용합니다. 엔진의 `Engine → Level → Actor` 구조는 원티드 포텐업 게임개발트랙 강의 과정을 기반으로 구현했습니다.

## 향후 계획

- 12층 이후 옥상 장면과 탈출 연출 추가
- 방·복도 템플릿을 조합한 층 생성과 무한 상승 모드 검토
- 소음과 층 체류 시간이 다음 층의 위험에 반영되도록 규칙 확장
- 경험치·장비와 피격 플래시·히트스톱·넥백 같은 전투 요소 검토
- 게임 상태 업데이트를 고정 틱으로 분리하고, 이후 Unity에서 같은 규칙을 확장하는 방향 검토

## 그래픽 에셋

일부 캐릭터 스프라이트는 AI 생성 이미지를 원본으로 사용했습니다.
게임에서는 원본 PNG 대신 콘솔 렌더러에 맞게 변환한 16색 인덱스 프레임을 사용합니다.

## 제외 범위

- 오픈월드와 온라인 멀티플레이
- 완전한 3D 건물 시뮬레이션
- 대규모 제작·인벤토리 시스템
- 이해하거나 검증하지 못한 AI 생성 코드를 그대로 채택하는 것
